# Расписание занятий — ПГТУ

Простой статический сайт: расписание пар по группам и звонки.
Личный неофициальный проект, не связанный с администрацией филиала.
Без сборки и зависимостей — достаточно открыть `index.html` в браузере.

## Что внутри

```
D:\Сайт для пгту\
├─ index.html        — разметка страницы
├─ privacy.html      — политика конфиденциальности
├─ manifest.json     — описание приложения для установки на главный экран
├─ sw.js             — service worker: офлайн-режим и установка
├─ css/styles.css    — оформление (цвета и радиусы в :root)
├─ js/data.js        — данные: факультеты, курсы, группы, дни, пары, звонки, занятия
├─ js/app.js         — логика: выбор группы, фильтры, отрисовка, часы, установка
├─ js/ads.js         — рекламный слот (по умолчанию выключен)
└─ icons/            — иконки приложения (192, 512, maskable, apple, favicon)
```

## Как пользоваться

- **Первый заход** — окно выбора: факультет → курс → группа. После кнопки «Показать расписание» на странице остаётся только выбранная группа.
- **Смена группы** — кнопка «Сменить» рядом с названием группы. Выбор запоминается на устройстве, поэтому при следующем заходе окно уже не появляется.
- **Неделя** — чётная / нечётная. По умолчанию включён режим **«Авто»**: неделя определяется по текущей дате (подсвечивается нужная кнопка). Ручной выбор недели отключает авторежим, кнопка «Авто» включает его обратно.
- **Звонки** — вкладка с временем пар и перерывов, а также круглые часы с текущим временем GMT+3.
- **Ссылка** — состояние хранится в адресе: `#faculty=uniit&course=1&group=ib-1-25&week=auto&view=schedule`. Короткая старая ссылка `#group=ib-1-25` тоже работает: факультет и курс определятся автоматически, адрес приведётся к полному виду.

Сейчас на сайте расписание для **1–4 курсов** УНИИТ: 1 курс — ИТ-1-26, ИИ-26, БС-26, ИБ-1-26, ИБ-2-26; 2 курс — ИТ-1-25, ИТ-2-25, ИИ-25, ИБ-1-25, ИБ-2-25, БС-25; 3 курс — ИТ-1-24, ИТ-2-24, ИБ-1-24, ИБ-2-24, БС-24; 4 курс — ИТ-1-23, ИТ-2-23, ИБ-1-23.

Ссылка **«Политика конфиденциальности»** в подвале ведёт на `privacy.html`. Страница статическая, входит в офлайн-кэш и не собирает данные.

## Установка на главный экран

Кнопка **«Добавить на главный экран»** находится под вкладками, справа.

- **Android (Chrome, Edge, Яндекс):** нажатие открывает системное окно установки — приложение добавится с иконкой на рабочий стол. Если браузер окно не показал, в подсказке будет путь через меню ⋮.
- **iPhone и iPad:** подсказка «Поделиться» → «На экран „Домой“». Только Safari умеет добавлять ярлыки, и делает это вручную — программно на iOS это запрещено.
- **Компьютер:** установка в отдельное окно приложения (Chrome/Edge) или подсказка в меню.
- Установленный сайт открывается без адресной строки и работает офлайн: service worker держит копию страницы в кэше.

Важно: установка, офлайн-режим и ярлык на телефоне работают только по **http/https**. С `file://` и по локальной сети без HTTPS браузер их не включит — то есть ярлык заработает после размещения сайта на хостинге.

## Как обновить расписание

Всё расписание лежит в `js/data.js`.

Занятие — один объект в массиве `lessons`:

```js
{
  day: 'mon',            // mon, tue, wed, thu, fri
  pair: 2,               // номер пары
  week: 'even',          // 'even' — чётная, 'odd' — нечётная, 'both' — каждая неделя
  groups: ['ib-1-25'],   // на какие группы идёт занятие
  type: 'lecture',       // lecture | practice | lab | coursework | pe
  typeLabel: 'Лек.',     // подпись над предметом
  subject: 'Физика',
  teacher: 'Тютюников',
  room: '5.410',
}
```

- Если пара общая для нескольких групп, перечислите их в `groups`.
- Пустые `teacher` и `room` просто не отображаются.
- Звонки правятся в массиве `bells`, дни — в `days`.

Факультеты, курсы и привязка групп — в массиве `faculties`:

```js
faculties: [
  {
    id: 'uniit',
    name: 'УНИИТ',
    courses: [
      { number: 1, groups: ['it-1-26', 'ii-26', 'bs-26', 'ib-1-26', 'ib-2-26'] },
      { number: 2, groups: ['it-1-25', 'it-2-25', 'ii-25', 'ib-1-25', 'ib-2-25', 'bs-25'] },
      { number: 3, groups: ['it-1-24', 'it-2-24', 'ib-1-24', 'ib-2-24', 'bs-24'] },
      { number: 4, groups: ['it-1-23', 'it-2-23', 'ib-1-23'] },
    ],
  },
],
```

`groups` внутри курса — это `id` из массива `groups`. Пустой список означает «групп пока нет»: в окне выбора появится подсказка, а занятия для такого курса не показываются. Чтобы добавить факультет, добавьте ещё один объект в `faculties`.

Автоопределение недели настраивается в `meta.weekRule`: укажите понедельник опорной недели и её чётность (`anchorMonday`, `anchorWeek`). От этой недели чётность считается в обе стороны, поэтому раз в семестр достаточно обновить одну дату.

Данные перенесены с фотографий и Excel-файла расписания, спорные ячейки сверены. При изменениях правьте только `js/data.js`.

После правок, если сайт уже размещён в интернете, увеличьте номер версии в `sw.js` (`var CACHE = 'pgtu-schedule-v6'` → `v7`): так у посетителей обновится офлайн-копия.

## Реклама и монетизация

Под расписанием есть слот `#ad-slot`, оформленный в стиле сайта. По умолчанию он **выключен** и не занимает места.

Настройка — в `js/ads.js`:

```js
var config = {
  enabled: false,     // true — включить показ
  provider: 'rsya',   // сеть: 'rsya' | 'adsense' | 'custom'
  scriptUrl: '',      // адрес скрипта сети
  blockId: '',        // номер рекламного места
  minHeight: 96,      // резерв высоты, чтобы макет не прыгал
};
```

Как устроено:

- пока `enabled: false` — блок скрыт, ничего не загружается;
- в офлайне слот исчезает сам (`online` / `offline`), интерфейс работает как раньше;
- сторонние запросы service worker не кэширует — реклама не попадает в офлайн-копию;
- высота резервируется заранее, поэтому при загрузке баннера не дёргается таблица;
- при печати блок скрыт.

Чтобы включить по-настоящему, понадобится:

1. Свой домен и хостинг, который разрешает рекламу (на `github.io` это риск нарушения правил GitHub Pages).
2. Аккаунт в сети: для РФ — РСЯ (Яндекс); Google AdSense для российских площадок не работает.
3. Подтверждение сайта в сети и файл `ads.txt` в корне.
4. Маркировка рекламы по закону РФ: пометка «Реклама», данные рекламодателя, токен ОРД (ERID) и передача сведений в ОРД.
5. Согласие на cookies и политика конфиденциальности — если реклама персонализированная.

Код сети вставляется в `mount()` в `js/ads.js`: скрипт грузится только онлайн и только один раз.

## Как добавить факультет, курс или группу

1. **Группа** — добавьте `{ id: 'new-id', name: 'НАЗВАНИЕ' }` в массив `groups`, а её id — в `courses[].groups` нужного курса.
2. **Факультет** — новый объект в `faculties`: `id`, `name` и список `courses` (курсы 1–4).
3. **Занятия** — в `lessons` укажите id новой группы в поле `groups`.
4. **Кэш** — поднимите версию в `sw.js` после загрузки файлов на хостинг.

HTML и CSS менять не нужно: окно выбора строится по данным из `js/data.js`. Ссылки уже человекочитаемые — `#faculty=uniit&course=1&group=ib-1-25`.

## Дизайн

Тёмно-зелёная тема: глубокий фон, приглушённые поверхности, мягкие акценты — рассчитана на долгое чтение без нагрузки на глаза.

- основные цвета — CSS-переменные в `:root` (`--bg`, `--surface`, `--accent`, `--border`, …);
- карточки занятий красятся по `type` (лекция / практика / лабораторная / курсовая / физкультура);
- один файл стилей, без фреймворков.
